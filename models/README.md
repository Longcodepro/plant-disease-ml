# Models Directory

Thư mục lưu trữ các Model Artifacts, Trọng số (Checkpoints) và Metadata:
- `class_indices.json`: Ánh xạ 38 nhãn giữa index số nguyên và tên lớp bệnh / cây trồng.
- `baseline1_simple_cnn.pth`: Checkpoint của Baseline 1 (Vanilla CNN từ đầu).
- `baseline2_mobilenetv2.pth`: (Sẽ cập nhật ở pha Transfer Learning MobileNetV2).
- `baseline3_resnet50.pth`: (Sẽ cập nhật ở pha ResNet50).
